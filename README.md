🎬 Movix

Movix is a modern movie discovery web application built using JavaScript and styled with Tailwind CSS, powered by the TMDB (The Movie Database) API. It allows users to explore trending movies, search for titles, and view detailed information about their favorite films.

⸻

Live Demo Link: movix-alpha-two.vercel.app

⸻

🚀 Features

* 🔍 Search Movies – Find movies instantly by title
* 🎥 Trending Movies – Discover what’s popular right now
* 📄 Movie Details – View ratings, overview, release date, and more
* ⚡ Responsive Design – Optimized for mobile, tablet, and desktop
* 🎨 Modern UI – Clean interface built with Tailwind CSS

⸻

🛠️ Tech Stack

* HTML5
* Tailwind CSS
* JavaScript (Vanilla JS)
* TMDB API

⸻

📦 Installation & Setup

1. Clone the repository

git clone https://github.com/your-username/movix.git
cd movix

2. Get your TMDB API Key
    * Sign up at https://www.themoviedb.org/
    * Generate your API key from your account settings
3. Add your API Key
    * Locate the JavaScript file where the API is used
    * Replace the placeholder with your API key:

const API_KEY = "your_api_key_here";

4. Run the project
    * Open index.html in your browser
        (or use Live Server in VS Code for a better experience)

⚠️ Limitations

* Users cannot save or favorite movies
* No authentication system
* Movies cannot be streamed (TMDB does not provide streaming)
* No local storage functionality implemented

⸻

🌐 API Used

    Provides movie data including titles, ratings, posters, and descriptions.
